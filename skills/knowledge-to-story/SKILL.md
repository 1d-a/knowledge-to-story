# knowledge-to-story：从知识点，给出串线物故事

这个 skill 只做一件事：用户给一组知识点（文字或截图），你给出几个**串线物故事雏形**。每个故事用一件东西串起全篇，高潮落在感动、悲伤、燃三类里的一种，情绪要足够强。

全程用中文。

## 开工前必读

动笔之前，先把这两个附件完整读一遍，不要只看这份 SKILL.md：

- `references/串线物研究.md`：串线物的完整研究，包括前人的说法、两把尺子（管多少事、几层意思）和它们的交叉、七种形态、八种命运走法、十部作品的逐一拆解、写法要点。挑串线物、定它的位置和走法，都按这份文档来。
- `references/样例.md`：用户认可的三个故事，是质量标杆；末尾还有三个反例，是用户指出的、科学和超自然背景撞车的错误。写之前对照着体会蓄力、代价和高潮里那句话，也看清反例错在哪。

## 这些故事是干什么用的

- 用来做知识点短视频。**主攻讲故事，顺便涉及知识点。**
- 目标只有一个：让观众对这个知识点感兴趣。不要求看完会做题，也不要求追下一集。
- 知识点不必全出现，**松散相关就行**。一组知识点里，挑一两条最能长出故事的来用。

## 硬规则（每个故事都必须满足）

1. **不是讲课。**不举例讲知识点，不提问引导思考，不出公式讲解，不人为制造一道"解题场景"。知识点在故事里自然露出就行，可以出现它的名字或相关的词。
2. **用到的规律必须是对的，而且必须真实地发生。**超自然的东西（仙人、剑气、妖怪、超能力）只能当舞台和角色，不能当知识点的"外挂"。知识点里的现象，必须按真实规律发生，在那个世界里照样成立。比如：仙人一剑斩出，先看见剑光、过几秒才听见雷声（光比声音快）；一拳打出去，自己反倒退了几步（力的作用是相互的）。每个故事都要过三道检查：
   - **谁发出**：知识点里的现象是谁、靠什么产生的？现实里它真能产生吗？（人发出超声波不行；蝙蝠发出超声波可以。）
   - **谁察觉**：是谁、靠什么察觉到的？现实里真能察觉吗？（人眼看见红外线不行；皮肤感到太阳的暖、蛇感知热、仪器测到都可以。）
   - **哪来的**：需要的工具或条件，那个世界里有没有？（武侠世界里的紫外灯不行；阳光、月光、把耳朵贴在地上听马蹄都可以。）
   拿不准就去查。`references/样例.md` 末尾有三个反例，写之前先看。
3. **落点只在三大类里选**：感动、悲伤、燃（见下方"落点速查"）。不用震撼、惊惧、爽。
4. **高潮的情绪必须足够强。**每个高潮都要过三关：
   - 蓄力够：高潮之前，观众已经在乎这个人了。
   - 有代价：主角拿要紧的东西去换，或者做了一个艰难的选择。
   - 有一句能击穿人的话：高潮里有一句台词或一个画面，一下子把情绪推到顶。
   - 另外，串线物最后一次出场，要接住全篇最大的转折。
5. **题材放开**：仙侠、武侠、科幻、历史真事、青春、神话、灾难、战争、都市等都可以，不局限于现实题材和情感题材。但**不写**：悬疑、童话、解题故事、侦探破案、穿越逆袭。
6. **不写会诱导学生模仿的危险行为**（比如趴在铁轨上听火车）。

## 三层别混淆

- **落点情绪**：看完留在心里的那一种，决定故事有多动人。只从三大类里选。
- **过程情绪**：好奇、紧张、惊险、好笑、憋屈、心疼，只负责拉着人往下看，不能当终点。
- **手法**：反转、悬念、伏笔回收、反差、留白，是制造情绪的办法，不是情绪。

## 落点速查

| 大类 | 具体落点 | 被什么击中 |
|---|---|---|
| 感动 | 温暖 | 人和人之间的情谊突然加深、被看见、和好 |
| 感动 | 崇高 | 看见了一个了不起的善举、牺牲、守诺 |
| 悲伤 | 心碎 | 永远失去的那一下 |
| 悲伤 | 遗憾（意难平） | 本来可以，就差一点：错过了、来不及了、没说出口 |
| 悲伤 | 怅惘 | 时间带走了一切，只剩某样东西还在 |
| 燃 | 热血 | 被逼到绝境，终于挺身而出、爆发出来 |
| 燃 | 悲壮 | 明知会输、会死，还是去做 |

余韵最长的多是复合情绪：悲壮（燃 + 悲）、含泪的温暖（心碎 + 温暖）、凄美（美 + 哀）、笑中带泪（一路好笑，最后落在感动或悲伤上）。

## 工作流程

用户给出知识点后，**直接出故事**，不先追问想法。用户如果附带了偏好（题材、落点、数量），照偏好来。

1. **读附件**：完整读 `references/串线物研究.md` 和 `references/样例.md`。
2. **拆规律**（自己做，不输出）：把知识点翻成几条大白话规律，再找真实例子和应用（生活里、自然里、历史上、技术上）。故事的种子多半藏在真实例子里。
3. **找串线物**：从规律和例子里，挑一件能串起全篇的东西。它可以是研究文档里七种形态中的任何一种。按两把尺子定它的位置，首选"推着走 × 一词多层"；再从八种命运走法里给它选一条命运线。
4. **先定落点，再定题材**：同一批故事里，三大类尽量都出现，题材各不相同，串线物的形态也别重复。
5. **搭骨架**：开头、蓄力、【高潮】、收尾、点睛。蓄力 2 到 4 条，要做到三件事：让观众在乎这个人；把知识点（规律）先埋下去；把绝境或代价推到顶。高潮时，让埋下的规律起作用。
6. **自检**（见下方清单），不过关的重写。
7. **输出**。

默认数量：每组知识点给 **3 个**故事。用户给了几组，就各给 3 个。

## 自检清单

每个故事逐条过：

- [ ] 落点在感动、悲伤、燃之内，且标清楚了大类和具体落点
- [ ] 高潮过了三关：蓄力够、有代价、有一句击穿人的话
- [ ] 串线物最后一次出场接住了最大的转折
- [ ] 串线物在两把尺子上的位置清楚，按研究文档的写法要点来写
- [ ] 用到的规律是对的
- [ ] 过了三道检查：谁发出、谁察觉、哪来的，都经得起现实推敲；超自然的东西没有被拿来当知识点的外挂
- [ ] 没有讲课、举例、提问、解题
- [ ] 题材不是悬疑、童话、解题、侦探、穿越
- [ ] 没有诱导模仿的危险行为
- [ ] 同一批里落点和题材没有扎堆
- [ ] 质量不低于 `references/样例.md` 里的三个样例，也没有犯反例里的错

## 输出格式

每个故事按这个格式，故事之间用二级标题分开：

```
## X.《标题》· 题材

- 落点：大类 · 具体落点（可加括号补一句，比如"带着泪"）
- 串线物：是什么（两把尺子的位置 + 一词多层的几层，如果有）
- 涉及的知识点：一两句大白话

开头：一两句。

蓄力：
- 2 到 4 条

【高潮】：一段，必须标出来。

收尾：一两句。

点睛：一句。
```

全部故事给完后，用一行列出这一批的落点分布，最后问用户最有感觉的是哪一个。

## 真实原型怎么处理

- 故事取材于真实事件或真实人物时，先上网查证关键事实（时间、地点、数字、原话），不凭记忆写。
- 故事本身可以虚构细节，但要在故事后面加一段"真实原型"说明，事实部分注明来源。
- 涉及真实的灾难和逝者时，写得克制、尊重，不渲染惨状。
